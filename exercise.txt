Ex. 9 React Fragments — Step by Step 
1. What is a React Fragment? 
A React Fragment allows us to group multiple elements without adding an extra HTML 
element such as <div> to the DOM. 
The syntax is: 
<> 
  <h1>Hello</h1> 
  <p>Welcome to React</p> 
</> 
The <>...</> is called a Fragment shorthand. 
 
2. Why Do We Need Fragments? 
A React component normally needs to return a single parent element. 
This will cause an error: 
function App() { 
  return ( 
    <h1>Hello</h1> 
    <p>Welcome</p> 
  ); 
} 
There are two separate elements at the top level. 
 
3. Solution Using <div> 
We can put them inside a <div>: 
function App() { 
  return ( 
    <div> 
      <h1>Hello</h1> 
      <p>Welcome</p> 
    </div> 
  ); 
} 
This works, but the <div> creates an extra DOM element. 
 
4. Solution Using Fragment 
Instead, use: 
function App() { 
  return ( 
    <> 
      <h1>Hello</h1> 
      <p>Welcome</p> 

    </> 
  ); 
} 
React groups the elements, but the Fragment itself does not create an extra DOM node. 
DOM structure 
With <div>: 
div 
├── h1 
└── p 
With Fragment: 
h1 
p 
 
5. Step-by-Step Example 
Step 1 — Create a component 
function Student() { 
  return ( 
    <> 
      <h2>Ajith Kumar</h2> 
      <p>Computer Science and Engineering</p> 
    </> 
  ); 
} 
Step 2 — Use the component 
function App() { 
  return ( 
    <div> 
      <Student /> 
    </div> 
  ); 
} 
 
export default App; 
Output 
Ajith Kumar 
Computer Science and Engineering 
There is no unnecessary <div> around the <h2> and <p> generated by the Student component. 
 
6. Full Example 
function Student() { 
  return ( 
    <> 
      <h2>Student Details</h2> 

      <p>Name: Ajith</p> 
      <p>Department: CSE</p> 
    </> 
  ); 
} 
 
function App() { 
  return ( 
    <div> 
      <h1>College Information</h1> 
      <Student /> 
    </div> 
  ); 
} 
 
export default App; 
 
7. Using Explicit <Fragment> 
Instead of shorthand: 
<> 
  <h1>Hello</h1> 
  <p>Welcome</p> 
</> 
we can use: 
import { Fragment } from "react"; 
 
function App() { 
  return ( 
    <Fragment> 
      <h1>Hello</h1> 
      <p>Welcome</p> 
    </Fragment> 
  ); 
} 
 
export default App; 
Both approaches create a Fragment. 
 
8. Fragment with key 
An important point is that the explicit <Fragment> syntax can accept a key. 
This is useful when rendering lists. 
import { Fragment } from "react"; 
 
function App() { 
 
  const students = [ 
    { id: 1, name: "Ajith" }, 
    { id: 2, name: "Ravi" } 

  ]; 
 
  return ( 
    <div> 
      {students.map((student) => ( 
        <Fragment key={student.id}> 
          <h2>{student.name}</h2> 
          <p>Computer Science</p> 
        </Fragment> 
      ))} 
    </div> 
  ); 
} 
 
export default App; 
Here: 
<Fragment key={student.id}> 
groups multiple elements for each student while providing a key. 
Important: The shorthand <>...</> cannot receive a key.

10. When Should We Use Fragments? 
Use Fragments when: 
✅ You need multiple elements 
<> 
  <h1>Title</h1> 
  <p>Description</p> 
</> 
✅ You don't need a wrapper element 
Instead of: 
<div> 
  <h1>Title</h1> 
  <p>Description</p> 
</div> 
use: 

<> 
  <h1>Title</h1> 
  <p>Description</p> 
</> 
✅ You want cleaner DOM structure 
Fragments avoid unnecessary <div> elements. 
 
11. Simple Real-World Example 
Imagine displaying student information: 
function Student() { 
  return ( 
    <> 
      <h2>Ajith</h2> 
      <p>Roll No: 101</p> 
      <p>Department: CSE</p> 
    </> 
  ); 
} 
The Fragment lets these three elements be returned together without creating an unnecessary 
wrapper. 
 
 Exam Answer 
What is React Fragment? 
React Fragment is a feature that allows multiple JSX elements to be grouped without 
adding an extra DOM element. It is commonly written using the shorthand <>...</>. 
Syntax: 
<> 
  <h1>Hello</h1> 
  <p>Welcome</p> 
</> 
Alternative syntax: 
import { Fragment } from "react"; 
 
<Fragment> 
  <h1>Hello</h1> 
  <p>Welcome</p> 
</Fragment>
